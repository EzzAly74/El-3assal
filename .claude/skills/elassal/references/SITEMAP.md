# ElAssal e-commerce — Site Map

> Dual-path storefront navigation. Generated from the client catalog (SKUs.xlsx + ITEM TREE.xlsx).
> Grouped & prioritized by product count per client feedback (no "مرصوصة" stacking).

## Global shell (every page)
- Top promo strip
- Utility header: search · cart · account · language (AR/EN) · **WhatsApp · Hotline · Branches**
- Primary navbar (below)
- Footer

## Primary navbar
1. **تسوق حسب القطعة** (Shop by Part) — mega menu
2. **تسوق حسب الماركة** (Shop by Brand)
3. **تسوق حسب الماكينة** (Shop by Machine)
4. **العروض** (Offers)

## Commerce funnel
`PLP → PDP → Cart → Checkout → Order Success`
