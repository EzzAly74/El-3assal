# ElAssal B2C Ecommerce IA Rules

Date: 2026-04-21

## Non-Negotiables
- This project is strictly **B2C ecommerce**.
- IA must follow a **storefront homepage-module architecture** (not corporate website tree style).
- UX priority is **smooth, simple shopping for non-technical users** (e.g., farmers, mechanics, small workshops).

## Reference Pattern (Homepage-First Ecommerce)
- Top Promo Strip
- Utility Header (cart, branches, hotline, WhatsApp, account, language)
- Main Search Row (search-first)
- Primary Mega Navigation
- Hero Carousel (campaigns)
- Trust/Service Strip (shipping, pickup, support, warranty)
- Shop by Machine/Brand
- Shop by Part Type
- Featured Products / Best Sellers
- Brand Rail
- Footer Links

## Shared Commerce Funnel (applies across entry points)
- PLP -> PDP -> Cart -> Checkout -> Order Success

## IA Modeling Principle
- Use **Homepage modules + connected funnel flows**.
- Avoid presenting the project as a generic corporate sitemap.

## Notes for Stakeholders
- Keep language and structure aligned with Egyptian retail ecommerce expectations.
- Keep support actions visible (WhatsApp, Hotline, Branches).
- Keep discovery dual-path: machine/brand path + part-type path.
